## Ficha técnica de la base de datos

Los tipos de datos que recolectó mi grupo y yo se pueden clasificar en base a su naturaleza cualitativa (artista, el género musical, la nacionalidad y escenario) y cuantitativa (año de edición,número de integrantes y número de presentaciones).

Las variables incorporadas en nuestra base de datos abarcan las siguientes columnas: edicion lolla (año), artista (nombre), genero musical 01, genero musical 02, genero musical 03, integrantes (número), nacionalidad, headliner (Sí/No), escenario y veces en lollapalooza(número).

A pesar de ser una base de datos muy grande con cientos de filas, es muy fácil de entender. Gracias a que cada columna tiene un filtro aplicado, se puede buscar información específica de manera rápida y sencilla.
