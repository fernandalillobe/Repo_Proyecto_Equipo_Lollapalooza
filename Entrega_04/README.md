# Manual de identidad y wireframe
Para nuestro manual de identidad decidimos guiarnos por el estilo visual que tiene la página web oficial de Lollapalooza Chile.

Por ello, nuestra paleta de colores se definió en base a este planteamiento. Entonces, nuestros colores se inspiraron en la página web del Lollapalooza, sus carteles y sus publicaciones de redes sociales. 

En cuanto a la tipografía, decidimos utilizar las fuentes Titan One y Fredoka One ya que estas transmiten una cierta informalidad, lo que las hace ideales para transmitir información de un evento asociado a la diversión y la música. Por su parte, también usaremos la fuente OpenSans para nuestro menú, ya que, al ser una letra con un estilo más común, permite darle el toque formal y periodístico a nuestra webstory.

En cuanto a nuestros recursos gráficos, decidimos que estos debían tener un estilo simple, ya que hacerlos muy llamativos, sumado a la diversa paleta de colores que utilizaremos, podría generar una saturación visual en las personas que ingresen a la webstory.

Además, para nuestro moodboard decidimos incluir imágenes que transmitieran el ambiente del festival: se observan artistas, público, y puestas en escena.
